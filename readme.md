# 🚗 OBD Diagnóstico IA

Aplicación web/PWA orientativa para consultar códigos OBD-II de vehículos.

## Funciones

✅ Pantalla de bienvenida

✅ Búsqueda por código OBD-II

✅ Selección de marca, modelo y año

✅ Explicación orientativa del código

✅ Posibles causas

✅ Procedimientos de comprobación recomendados

✅ Historial de consultas

✅ Favoritos

✅ Lectura por voz

✅ Enlaces a vídeos de reparación

✅ Generación de informes PDF

✅ Compatible con móvil Android

✅ Instalable como PWA
